# Pricing — Tokenscope

Tokenscope is **free**.

- Price: $0. There is no paid tier, no subscription, no in-app purchase, and no account.
- License: MIT (open source). Source code: https://github.com/HduSy/tokenscope
- Telemetry: none. The app reads local log files only — no network calls, no analytics, no data sold or shared.

There is nothing to buy. Install it and use it.

## Install

- macOS: `brew install --cask hdusy/tokenscope/tokenscope` (or the `.dmg` from GitHub Releases)
- Windows: `.exe` (x64) installer from GitHub Releases
